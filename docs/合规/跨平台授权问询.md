## 1. 为什么要书面问询

pcl-next 是 PCL2 的第三方修改版（fork），属《PCL 存储库合理使用指南》定义的**重度使用**
（基于存储库修改 + 重新实现启动 / 下载 Java 版 Minecraft 的实质功能）。
指南本身声明「不是法律文件或协议」，且「除《PCL 分发有限许可》明确授予的权利外，
开发者保留软件及其相关知识产权中的全部权利」；真正的授权范围写在**石墨文档**里的
《PCL 分发有限许可》，而该文档正文需 JS 渲染，无法程序化抓取核验。
因此「修改版能否再分发」「能否扩展到 Windows 以外的平台」这两件事，
不能靠社区副本或公告推断，必须向上游作者本人确认并留存答复。

## 3. 必须问清的五个问题

1. **授权范围冲突**：#7 与 #8 对「是否允许分发派生作品」口径相反。请确认《PCL 分发有限许可》当前版本，以及以哪份文本为准。
2. **平台适用性**：第三方修改版运行在 Android / Linux 等非 Windows 平台时，是否同样适用《合理使用指南》？是否需要单独授权？
3. **L5 的平台边界**：第 5 条「界面主要色相必须为蓝色」原文限定「**在 Windows 系统上运行时**」。非 Windows 平台是否不受此约束？
4. **命名**：禁用词「PCL 手机版」——若采用不含该词、但带平台信息的名称，是否仍会被视为暗示官方移动端？请给出可接受的命名口径。
5. **上游意愿**：#9 表明上游不会自制其他系统版本。这是否意味着也不希望第三方推出跨平台版本？若作者不希望，本项目将停止安卓线。
