### 本组逐文件结论

- **`MyButton.xaml.cs`**：无新增问题。`PanFore` / `LabText` 强转与事件订阅均与 XAML、VB 对齐；重复订阅的两个 MouseEnter/Leave/Up 各司其职（颜色动画 + 按下判定），无双触发。`RefreshColor` 外层有 try 兜底（:236）。
- **`MyCard.cs`**：风险集中在 `Children[3]` 强转（上半 #8）、`AniDispose` Parent 判空（同 MyCard :441/458 已有判断，本文件内一致）；折叠点击判定三元 `IsSwapped` 冗余但与 VB 一致，非反转；高度动画分段参数与 VB 逐段对齐。已知项见下半 C1 / C2。
- **`MyCheckBox.xaml.cs`**：仅 `bool.Parse` 脏值风险（上半 #7）；`ShapeCheck.RenderTransform` XAML 为 `ScaleTransform`（`MyCheckBox.xaml:11`），强转安全；`PreviewChange` 仅在 `value && user` 触发与 VB :44 一致，非分支遗漏。
- **`MyComboBox.cs`**：本组风险最集中——数字解析脆化（#1）、可编辑文本框 null NRE（#2）、dynamic 模板解析 null（#6）、Child 强转同源（#12 跨组）；`MouseLeave` 订阅到 `EventArgs` 参数方法靠逆变匹配，编译合法、语义无影响（已排除误报）。
- **`MyDropShadow.cs`**：除零（#17）与负半径（#18）两处几何边界风险；静态 `_commonBrushes` 初始化有 `lock` 保护（:373），`OnRender` 走 UI 线程无并发解引用；9 段 brush 枚举索引与 `Placement` 0–8 对齐，无越界。
- **`MyExtraButton.xaml.cs`**：重复订阅（#9，确认非活跃）、进度比例未钳制（#10）、Logo converter（#11）；`PanScale` / 根 `Grid` RenderTransform XAML 均为 `ScaleTransform`（`MyExtraButton.xaml:7/12`），强转安全；禁用 / 指向 / 普通颜色三分支与 VB 一致。
