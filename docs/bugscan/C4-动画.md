## 二、覆盖清单（已逐项核对，未发现缺陷的点）

### 2.1 并发 / 生命周期 / 资源

- **事件订阅退订**：本文件无任何 `+=` 事件订阅，不存在退订遗漏。
- **资源释放**：未创建 `Storyboard / AnimationTimeline / Brush / 位图`；自建 `TranslateTransform / ScaleTransform / RotateTransform` 挂到元素 `RenderTransform`，随元素 GC 回收，无 `IDisposable` 泄漏面（卸载残留问题见 1.2 对应条目）。
- **动画组键碰撞**：`Name` 为空时用 `NewEntry.Uuid` 兜底（`:973-976`）；有名组先 `AniStop(Name)` 再 `Add`（`:979-981`），同一路径内无重复键；完成删除按 `Uuid` 匹配而非按名字（`:1155-1162`），避免误删执行中新加入的同名组。
- **`IsAfter` 串行语义**：`CanRemoveAfter` 先置 `true`，遇到非 After 动画置 `false`；After 动画在前置未完成时 `break` 退出本组（`:1107-1143`），与 VB `:873-902` 一致，无分支反转。

### 2.2 数值 / 边界 / 可空

- **透明度钳制**：`UIElement.Opacity` 与 `DropShadowEffect.Opacity` 均 `Clamp(0,1)`（`:1248 / :1253`）。
- **非负尺寸/线宽**：`Width/Height`（`:1261 / :1267`）、`StrokeThickness`（`:1282`）、`ScaleX/ScaleY`（`:1395 / :1396`）、`Scale` 宽高（`:1342 / :1343`）、`GridLength.Value`（`:1316`）均 `Math.Max(…, 0)`；`Width/Height` 为 `NaN` 时回退 `ActualWidth/ActualHeight`（`:1261 / :1267`）。
- **`Width/Height` 初始 NaN**：已用 `double.IsNaN` 分支处理，未发现遗漏。
- **工厂缓动兜底**：全部 `Aa*` 工厂 `Ease ?? new AniEaseLinear()`，常规调用路径 `Ease` 非空。
- **帧级异常隔离**：`AniRun` 整体 `try/catch`（`:1180-1420`），单动画异常不拖垮整帧；`AniTimer` 外层另有 catch（`:1168-1171`）；异常经 `Logger.Error` 上报。
- **Color 终态引用**：资源色动画完成时 `SetResourceReference` 回挂资源（`:1122-1123`），与 VB `:885` 一致；`ValueLast` 记录小数余量（`:1333`）。
- **`AniSpeed` 取值**：调试档 `≥30 → 200`，否则 `Setting*0.1+0.1` 钳制 `[0.1, 3]`（`:34-35`），负设置被下限兜住。

### 2.3 枚举 / 类型映射

- **`AniType` / `AniTypeSub` 分支覆盖**：`AniRun` 的 `switch` 覆盖工厂产出的全部分支——Number 下 `X/Y/Width/Height/Opacity/Value/Radius/StrokeThickness/BorderThickness/TranslateX/TranslateY/Double/DoubleParam/GridLengthWidth`（`:1192-1318`），`Color/Scale/TextAppear/Code/ScaleTransform/RotateTransform`（`:1325-1412`）；无未映射枚举落入空分支。
- **`Double` 依赖属性数组**：工厂 `new[] { Obj, Prop, "" }`（`:475`），执行侧 `[0]/[1]/[2]` 下标对齐（`:1306`）。
- **`BorderThickness` 只取 `Bottom`**：`:1287` 单值 `Thickness(Bottom + Delta)`，与 VB `:982` 同形，属上游既有行为，不计为新缺陷。
- **`Scale` 右/下边距用 `Left/Top` 差值**：`:1341` 与 VB `:1010` 同形（`MyRect` 四字段语义上游如此），不计为新缺陷。
- **字符串键比较**：组名仅做 `IsNullOrEmpty` 与字典键匹配，无大小写/空格归一化需求；`FindResource(Res)` 按 WPF 资源键语义。

### 2.4 线程 / 封送

- **封送方向**：`AniTimer` 经 `RunInUiWait`（同步 `Dispatcher.Invoke`，`ModBase.cs:1118-1128`）回到 UI 线程执行；`AaCode` 回调在该上下文内同步调用（`:1381`），与注释「主线程调用」一致。
- **帧间隔钳制**：`DeltaTime` 与 FPS 计时差值均 `Clamp(0, 100000)`（`:1034 / :1041`），时钟回拨/长暂停不会出负间隔。
- **`RunInNewThread` 兜底**：线程入口外层 `try/catch` 记日志（`ModBase.cs:1093`），未捕获异常不会静默退出。
