## 二、覆盖清单（已核对，不计为新 bug）

### 2.1 上游已登记 / 同构留痕

- **`On Error Resume Next`（清单§四，ModValidate:270）**：C# 侧已重构为显式 `try/catch` 三类目录异常（`DirectoryNotFoundException` / `UnauthorizedAccessException` / `IOException`，ModValidate.cs:331-346），注释说明「枚举失败按无忽略项处理」；`On Error Resume Next` 形态在 C# 侧已消除，属已处置。
- **加载器任务链相关技术债**：本文件并发状态机（L1）、输入失败状态残留（L2）、CTS/事件/字典泄漏（L3/L4/L5）均为上游 VB 同构遗留，C# 侧复核仍在；清单§四/§十的加载器取消残留口径继续适用，未发现 C# 新引入的分支反转。
- **上游 issue #9360（Mod 并发更新替换失败）**：属 `ModDownloadLib`，不在本组文件，未重复排查。
- **#9440 启动取消状态残留**：主链路在 `ModLaunch`，本组仅复核到 `LoaderTask.Cancel()` 仅在 `Loading` 态置 `Canceled`（ModLoader.cs:502-504）、`TriggerThreadInterrupt()` 把 `LastRunningThread` 置 null（:517），任务链自身取消标志处理与 VB 一致；主链路残留需在 `ModLaunch` 组复核。
