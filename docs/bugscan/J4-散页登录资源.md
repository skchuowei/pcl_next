#### J4-07 ⚠️ `PageSelectLeft.xaml.cs:308`、`:456` —— 历史条目不含 `>` 时 `Split(">")[1]` 越界（上游 VB 同构继承）

- **现象**：刷新/重命名文件夹列表时，对 `Settings["LaunchFolders"]` 拆出的每个条目直接 `Folder.Split(">")[1]`，未先判 `Folder.Contains(">")`。
- **代码证据**：
  - `:308` `Folder.Split(">")[1]`（`RefreshCurrent` 内 `AddFolder` 单行 lambda）；
  - `:456` 同形（`RenameFolder` 内）；
  - 对照 `:408` `RemoveFolderFromSetup` 先判 `!Folder.Contains(">")` 再 continue，说明作者知道需要该判断，但这两处漏了。
- **根因**：`LaunchFolders` 为 `显示名>路径` 拼接格式；若历史配置/手工写入存在不含 `>` 的非空条目（空串已被 `continue` 跳过），`Split` 结果长度为 1，取 `[1]` 抛 `IndexOutOfRangeException`。
- **触发前提**：`LaunchFolders` 中存在不含 `>` 的非空条目（异常配置/旧版本残留）；正常由本程序写入的数据格式完整，不触发。
- **归类**：上游 VB 同构继承（`PageSelectLeft.xaml.vb:201`、`:379` 同样 `Split(">")(1)` 未先判）。外层 `RefreshCurrent` 有 try/catch 吞掉，不崩溃，但对应文件夹不显示。
- **建议**：两处取 `[1]` 前补 `if (!Folder.Contains(">")) continue;`，与 `:408` 口径一致。

#### J4-17 ⚠️ `MyResourceItem.xaml.cs:160-185` —— 空桩下载子页静态字段未初始化时 `.Content.Loader...` 空引用（上游 VB 同构继承，迁移保留）

#### J4-19 ⚠️ `PageResource.xaml.cs:249-250` —— 结果列表为空时 `GetRange(-1, …)` 越界（上游 VB 同构继承）

- **现象**：`Load_OnFinish` 计算 `Index = Math.Min(Page * PAGE_SIZE, Results.Count - 1)`；当 `Results.Count == 0` 时 `Count - 1 = -1`，`Index = -1`；随后 `GetRange(-1, Math.Min(0 - (-1), 40))` = `GetRange(-1, 1)`，抛 `ArgumentOutOfRangeException`。
- **代码证据**：`:249` `int Index = Math.Min(Page * PAGE_SIZE, Storage.Results.Count - 1);`；`:250` `GetRange(Index, Math.Min(Storage.Results.Count - Index, PAGE_SIZE))`。
- **根因**：未在取范围前先判 `Results.Count > 0`；空结果（网络失败、无匹配版本、源降级后无命中）是常见场景。
- **触发前提**：`Storage.Results` 为空集合；外层 `:275` catch 记 `Logger.Error` 后列表保持空白，不崩溃，但用户看到空列表且日志为异常而非正常空态。
- **归类**：上游 VB 同构继承（`PageResource.xaml.vb:181-182` 同式）。
- **建议**：`:249` 前补 `if (Storage.Results.Count == 0) { 清空 UI + 按空态渲染提示; return; }`。
