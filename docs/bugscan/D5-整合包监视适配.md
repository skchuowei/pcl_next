## 二、覆盖清单（已核对，不计为新 bug）

### 2.1 上游已登记 / 已知缺陷留痕

- **#9412 / L2 `FileName`/`fileName` 大小写失配**：上游已知，C# 侧复核仍在。`ModModpack.cs:457` 仍取 `ModJson?["FileName"]`（CF 文件 API 字段为小写 `fileName`），缺字段时 `GetValueOrDefault()` 退为 false，jar 后缀判断失效；形态与上游 `ModModpack.vb:285` 一致，未发现 C# 新引入的额外分支。

- **#9482 窗口变化跟丢**：上游已知，C# 侧复核仍在。`ModWatcher.cs:337-338` 找到窗口后 `IsWindowFinished = true` 直接短路后续枚举；`:359` 句柄 `WindowHandle` 固定后不再刷新；游戏重启 / 换窗 / 句柄失效后不会重新枚举。与 `ModWatcher.vb:266/281` 同形。
- **ModModpack.vb:377 Unknown 键模型缺陷（TODO）**：上游已知，C# 侧复核仍在。`ModModpack.cs:580-581` 保留 `var TargetVersion = new McVersion("Unknown");` 与 TODO 注释，未做「一个版本名一个字典」重构。
- **#9475 幽灵版本**：不在本组文件（属 ModMinecraft 版本列表），未重复排查。
