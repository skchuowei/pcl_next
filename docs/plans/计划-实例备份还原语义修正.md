# 计划：实例备份还原语义修正与还原进度弹窗

> 2026-11-14。用户口径：「整合包备份是导入包备份，还原就是要全部重新下载，所以相当于删除游戏然后重写下载；另外还原时用户操作可能会打断，还原时弹弹窗，显示当前进度、阶段，无法关闭，完成后自动关闭。」

## 一、目标

1. **整合包备份 = 导入包留档**：不再对「mods/configs/saves」等目录拍文件快照，而是把导入该实例时用的原始整合包文件（zip / mrpack / 各平台整合包）原样复制到 `versions\<实例名>\backups\imported\` 并写一份只含包信息的清单。
2. **还原导入包备份 = 删内容 + 全量重下**：清空实例内容根下的全部文件（保留 `backups`），再按留档的整合包跑一遍完整安装流程（Mod、资源、游戏本体全部重新下载），等价于删掉实例重装。
3. **还原期间不可被打断**：进入还原后弹出一个模态进度弹窗，显示当前阶段文案 + 百分比进度，无任何按钮、不可关闭；任务结束后由程序自动关闭。

## 二、现状与问题

- `ModBackup.BackupKind.Modpack` 原本是「范围快照」：按 `ModpackFolders` / `ModpackFiles` 白名单把文件打进 zip，还原时清空同名范围再从 zip 回放。这与用户对「整合包备份」的理解不一致。
- 还原走 `LoaderTask` + 任务栏，用户可以在还原进行中继续点页面、切实例、甚至启动游戏，容易与还原过程抢占同一批文件。
- 弹窗体系只有 `MyMsgText` / `MyMsgInput` / `MyMsgSelect` / `MyMsgLogin` 四种，没有进度型弹窗。

## 三、改动文件与要点

| 文件 | 改动 |
|---|---|
| `Controls\MyMsg\MyMsgProgress.xaml(.cs)` | 新增：不可关闭的模态进度弹窗。标题 + 阶段文案 + 进度条 + 百分比，`Report(percent, stage)` 可由后台线程调用，`Finish()` 淡出并 `PopModal`。 |
| `Modules\ModMain.cs` | `MyMsgBoxType` 增加 `Progress`；`MyMsgBoxTick` 增加对应分支；新增 `MyMsgProgressHandle`（线程安全缓冲进度与阶段，控件未创建前先缓存）与 `ModMain.MyMsgProgress(title, stage)`；恢复被误删的 `#region 页面声明` 头。 |
| `Modules\Minecraft\ModBackup.cs` | 新增 `BackupKind.Import`（标签「导入包」）、`BackupItem.PackFile`；清单新增 `Pack` 字段与 `ResolvePackPath`；新增 `SaveImportPack` / `FindImportPack` / `RestoreFromImportPack`；`Restore` 在遇到 `Import` 或带 `PackFile` 的条目时转走导入包还原；`AppendInitialBackupTask` 增加 `PackAddress` 参数，并追加「留档整合包原文件」步骤。 |
| `Modules\Minecraft\ModModpack.cs` | 5 处 `AppendInitialBackupTask` 调用补传 `FileAddress`，让每次导入都留档原始包。 |
| `Pages\PageInstance\PageInstanceBackup.xaml(.cs)` | 「整合包备份」按钮改为解释性动作（已有导入包→提示无需手动创建；没有→提示无法生成）；列表新增「导入包备份」分组；还原改走模态进度弹窗 + 后台线程，还原确认文案按类型区分；完成后刷新实例列表与设置缓存。 |

## 四、明确不做

- 不改 `BackupKind.Modpack`（范围快照）本身：还原前兜底 `PreRestore` 仍可能在「最近无完整备份」时使用 `Scope.Modpack`，这条链路保持原样。
- 不做「选择任意整合包文件重装」的入口（只有导入时留档的包才可还原）。
- 不做还原中断续传 / 断点恢复。

## 五、验证

1. `dotnet build pcl-next\pcl-next.csproj -c Release -r win-x64 --self-contained -p:PclChannel=Dev` → 0 错误。
2. 产物自包含完整性：目录含 `coreclr.dll`、文件数 286；双击能起主窗口。
3. 手动冒烟（待用户侧确认）：导入一个整合包 → 备份页出现「导入包备份」条目 → 点还原 → 出现不可关闭进度弹窗、阶段文案随流程推进、完成后自动关闭、实例内容为重新下载结果。

## 六、回滚

- 全部改动集中在上述 5 个文件，且不涉及对外接口变更；回滚方式为按文件清单反向撤销，`backups\imported\` 目录可保留（对旧逻辑无副作用，旧代码不认识该目录只会忽略，`KindFromFolder` 落到 `PreRestore` 分支需注意：回滚时应同时清掉该目录或回滚 `KindFromFolder`）。
