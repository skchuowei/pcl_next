# 计划：卡片透光材质（MyCard 半透明化）

> 触发：2026-11-20 用户反馈「现在的卡片背景透明有问题……太实，看不到透光」。
> 范围：仅 Windows 线 `dev-Windows` 的卡片底色材质，不动平台线、不动发布流程。

## 1. 目标

1. 让 `MyCard` 的底色具备「上缘透光、底部实色」的玻璃质感：窗口背景（主题渐变 / 背景图 / 全局模糊层）能从卡片上缘渗进卡片。
2. 可验证标准：
   - 浅色主题、默认渐变背景，卡片上缘像素约 `(231,245,252)`，底部约 `(241,252,254)`，卡片外背景约 `(209,230,246)`；
   - 卡片上缘与侧栏 `ColorSidebarGlass`（alpha≈150）观感同族，不再「一边透、一边实」；
   - 悬停卡片时只有外圈阴影加深，卡片内部不发灰。
3. 明确不做：不做逐卡片局部毛玻璃（2026-11-14 用户已否决侧栏局部模糊：与背景割裂、实景照片显脏）；
   不改弹窗 / 提示条 / 下载浮层 / 侧栏笔刷；不动全局 `ImgBack.Effect`。

## 2. 前置条件与阻塞项

- 参照物：侧栏 `ColorBrushSidebarGlass`（`ColorSidebarGlass`，浅/深 alpha≈150，2026-11-14 落地）。
- 2026-11-13 的 `UiCardBlur` 全局限模糊方案已 revert（`e5bf4b4`），本计划不复活该方案，也不恢复设置项。

## 3. 现状分析

- `ColorBrushCard` 是实色：深色 A=242 / 浅色 A=245。卡片几乎完全盖住背景，看不出透光。
- 侧栏已经改成半透明蒙层，于是同一页里侧栏能看到背景、卡片看不到，割裂感明显。
- 不能直接下调 `ColorCard`：它同时被 `ColorBrushBackgroundTransparentSidebar` 与下载浮层（`PageDownloadInstall` 主题浮层）共用，
  改它会连带改侧栏和浮层（2026-11-14 经验文档已明确「蒙层透明度不能直接改 ColorCard」）。
- `MyDropShadow` 的中心是**整块实心填充**（`Placement.Center` 用 `SolidColorBrush`），
  原先被不透明卡片完全盖住；卡片一旦半透明，这块阴影会从卡片内部透出来，悬停时 `Opacity` 升到 0.4，整卡会明显发灰。

## 4. 改动文件清单

| 文件 | 改动 |
|---|---|
| `pcl-next/Application.xaml` | 新增默认 `ColorBrushCardGlass`（浅色 0.60 / 0.84 / 0.96 竖向渐变），供主题刷新前的兜底与设计期 |
| `pcl-next/Modules/ModSecret.cs` | `ThemeRefresh` 里按主题重算 `ColorBrushCardGlass`（基色取 `ColorCard` 的 RGB，只换 alpha） |
| `pcl-next/Controls/MyCard.cs` | `MainBorder` 改绑 `ColorBrushCardGlass`；`MainChrome.SkipCenterFill = true` |
| `pcl-next/Controls/MyDropShadow.cs` | 新增 `SkipCenterFill` 依赖属性：跳过中心整块填充，只画圆角外侧一圈 |

不做：`ColorBrushCard` 本身（保持实色，供浮层）、`ColorSidebarGlass`、`MyMsg`、`PageDownloadInstall`、`ImgBack`。

## 5. 改动要点

1. **渐变取值**（竖直线性渐变，`StartPoint=(0,0)`、`EndPoint=(0,1)`，坐标按卡片高度）：

   | 主题 | 上缘 | 0.45 | 底部 |
   |---|---|---|---|
   | 浅色 | 153 (0.60) | 214 (0.84) | 245 (0.96) |
   | 深色 | 148 (0.58) | 209 (0.82) | 240 (0.94) |

   - 透光只集中在标题区，正文落在 ≥0.84 的下半区；即使将来用户设置背景图，正文也压在 84% 以上的底色上。
   - 深色取比浅色再透一点：深色卡片本身比背景暗，透出来的蓝调更明显，底部仍保留 0.94 保证正文。
   - 基色取 `ColorCard` 的 RGB：必须用两参 `new ModBase.MyColor(newA, ColorCard)`。
     **不能**用三参 `MyColor(a, r, g)`——三参是 `(R,G,B)`、A 恒为 255（2026-11-14 ⑦补 的踩坑）。

2. **阴影只留外圈**：`MyCard` 构造时给 `MainChrome` 设 `SkipCenterFill = true`；
   `MyDropShadow.OnRender` 画完四条边与四个角后若 `SkipCenterFill` 为真，`Pop()` 掉 GuidelineSet 直接返回。
   - 对外圈阴影的视觉无变化：中心那块本来就被不透明卡片盖住，外圈 3px（`ShadowRadius=3`）才是肉眼可见的部分。
   - `PageDownloadInstall` 的浮层阴影不设该属性（默认 `false`），行为不变。

3. **缓存**：`CardGlass.Freeze()` 后再塞进 `Res`，避免每次渲染重新求值渐变。

## 6. 回归影响面

- 所有 `MyCard`（启动主页、下载、联机、设置、扩展市场等，共约 118 处引用）。
- 主题：浅色 / 深色 / 旧版深色（`LegacyDark`）三种分支都走同一段 `ThemeRefresh`，值只按 `IsDark` 二分。
- 弹窗、提示条、下载浮层使用独立笔刷，不受影响。
- 悬停动画只改 `MainChrome.Color` 与 `Opacity`，`SkipCenterFill` 不参与动画。

## 7. 验证步骤

1. `.\scripts\Build.ps1`（默认 Dev / win-x64）→ 0 错误。
2. 启动后 `PrintWindow` 抓窗口：
   - 浅色：卡片上缘 ≈ `(231,245,252)`、底部 ≈ `(241,252,254)`、背景 ≈ `(209,230,246)`；上缘明显带背景蓝调。
   - 深色：卡片上缘比底部更接近背景的蓝，底部仍接近实色。
   - 圆角处无发黑弧边（`SkipCenterFill` 只去中心，四角仍保留外圈）。
3. 鼠标悬停卡片：外圈阴影加深、卡片内部颜色不变（不发灰）。
4. 打开联机 / 设置 / 扩展市场 / 启动页各扫一眼，确认正文与标题在小字号下仍清晰。

## 8. 回滚方案

- 一行回退：`MyCard` 里把 `"ColorBrushCardGlass"` 改回 `"ColorBrushCard"`，卡片立即回到实色；
  `MyDropShadow.SkipCenterFill` 默认 `false`，不改 `MyCard` 时对其他调用方零影响。
- `ColorBrushCardGlass` 可保留在 `Application.xaml` 与 `ThemeRefresh` 里不再被引用，不影响构建。
- 完整回退需同时撤销上述 4 个文件的改动，按《AGENTS》§六出回退报告。
