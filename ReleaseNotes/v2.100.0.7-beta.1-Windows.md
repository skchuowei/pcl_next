# pcl-next 2.100.0.7-beta.1（Windows 公测版）

> **单人自检版本，未经外部用户测试，欢迎反馈。** 本版由单人开发完成全流程门禁自检，
> 没有真实用户反馈输入。如果你在使用中遇到崩溃、卡死、存档/配置丢失，请按文末方式反馈。

这是 beta 阶段的第一版，代码基线就是上一版 `alpha.1`（提交 `3de5696`）。
**本版没有新增代码修复**——从 alpha.1 到现在，代码层只改了一行版本号常量，其余都是文档。
beta.1 的意义不在于"加了什么"，而在于完成阶段流转，并把制品放到更大的验证面上。

## 项目现状

Windows 线的 C# 重写已经走完：`pcl-next` 工程里 0 个 `.vb` 文件，C# 工程是唯一的编译入口。
代码实质仍带 VB 语义残留（`dynamic` 339 处、`Microsoft.VisualBasic` 转换函数 387 处），
这类残留编译时不会报错、只在运行时暴露，是后续代码质量主线，不影响本版发布。

## 本版本改动

### 代码层

无。相对 alpha.1 唯一的代码改动是 `VersionCode` 从 5020 提升到 5060（阶段晋级标识），
不影响任何运行时行为。

### 工程与流程层

- 晋级单人快速发布通道：按 2026-11-20 裁决，准出条件改为「≥1 个内测版 + 静默观察窗 +
  最小自检门禁全绿」，不再依赖外部用户反馈数量。规则改动见仓库根 `AGENTS.md` /
  `分支与发布规范.md` 顶部覆盖性声明。
- 沉淀 alpha.1 发布暴露的三类问题到规则文档，供后续版本避坑。
