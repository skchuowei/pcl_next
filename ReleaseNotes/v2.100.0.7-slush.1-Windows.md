# pcl-next 2.100.0.7-slush.1（Windows）

> **内测版（slush 阶段首版）**。本版标志着 **`dev` 开发阶段结束、`slush` 稳定化阶段开始**：
> Windows 线的 VB.NET → C# 全量重写已完成并在编译链中彻底移除 VB 源文件，
> `dev` 渠道**自本版起冻结**，不再接收新功能提交，只做缺陷修复，直至 `rc` 发布。
>
> 标签 `v2.100.0.7-slush.1-Windows`，制品仅 **Windows / win-x64**。
> 本版**进入内测**：仅供内测人员与开发者验证使用，不进任何公开更新通道，不承诺功能完整与配置兼容。


  暂存于本地开发分支，待 `rc` 之后按代号阶梯重新排期。

## 本版本改动

相对上一发布 `v2.100.0.6-dev.7-Windows`：**216 个文件变更，+2630 / −44723 行**。

### 1. VB.NET 源文件全量退出编译链（迁移收尾）

- 删除 **123 个孤儿 `.vb` 源文件**（43788 行），这些文件的 C# 版本早已就位，VB 副本只是残留；
- 删除 `pcl-next.vbproj`（288 行），`pcl-next.csproj` 成为唯一编译入口；
- 删除 VB 时代的 `App.config`、`*.settings` 与 7 个与之绑定的 CI 工作流文件；
- 结果：`pcl-next` 工程内 `.vb` 文件数 **0**，`git ls-files` 与磁盘视角一致。

### 2. 构建标识可追溯机制

- 构建标识新增**内容指纹与 UUID**（`Directory.Build.props` + `Get-BuildSmallVersion.ps1`），
  产物可反查构建时的提交与工作区状态；
- 禁止在版本段手工追加后缀，版本段只接受脚本写入。

### 3. 上游身份残留清理

- 清理上游 PCL 身份残留文件，避免产物中混入上游项目标识（许可 L1/L3 义务）。

### 4. 未完成新功能剥离（不计入本版功能）

以下改动**未进入本版**，已回退并另存于本地开发分支：

| 功能 | 回退方式 | 另存位置 |
|---|---|---|
| 卡片毛玻璃效果（`UiCardBlur` / `ModBlur`） | `git revert` + 手工解冲突（`Settings.cs` 设置表、卡片渲染参数） | 本地分支 `local/backup-features-20261113` |
| OKLCh 深色配色与旧/新版切换（`ModOklch`） | `git revert` | 同上 |
| 账号列表页（`PageSetupAccount`）与设置页接线 | 剥离悬空接线（`FrmSetupAccount` 字段、3 处 `SetupAccount` 分支、`ItemAccount` 入口） | 同上 |
| 高级设置页、颜色编辑器 | 未提交，移出工作区 | `D:\bing\MC\pcl_x\.wip\20261113-newfeatures\` |

> 剥离原因：这些改动在开发期只完成了一半接线（页面文件未提交、设置项已提交），
> 留在稳定版会导致编译失败或运行必崩，且按渠道纪律新功能不进入稳定版。

### 5. 版本常量切换

- `ModBase.VersionBaseName` → `2.100.0.7`，`VersionCode` → `5010`，`PclChannel` → `Slush`；
- `AssemblyInfo` 的 `AssemblyVersion` / `FileVersion` → `2.100.0.7`；
- 由 `scripts/Set-VersionInfo.ps1` 按标签机械写入，未手工改常量。

## 已知问题

1. **Linux / Android 线未完成迁移**：两条平台线各仍有 122 个 `.vb`，本版"VB 迁移全部完成"仅指 Windows；
   两条平台线在 `main` 与 `slush` 同步期间不受影响，但不得对外宣称已完成。
2. **平台制品未分发**：Linux / Android 制品在上游授权书面答复留存前不对外分发。
3. **内测范围有限**：本版仅经本机冒烟（启动、页面切换、帮助扫描），未覆盖全部玩法链路（下载、安装、启动游戏）的逐项回归。
4. **本地新功能未入库**：毛玻璃、OKLCh、账号列表页等仍在本地分支/暂存目录，后续重新排期，不做跨分支手工拷贝。
5. **构建环境依赖**：`pcl-next.csproj` 的构建信息生成步骤调用 `powershell`（Windows PowerShell 5.1）；
   仅有 `pwsh` 7 的环境该项静默跳过，需手工生成 `obj/<配置>/PclBuildInfo.g.cs` 才能编译。

## 升级说明

- **从 `dev.6` / `dev.7` 升级**：配置与用户数据目录结构未变，可直接覆盖 exe；设置项无新增/删除（毛玻璃、OKLCh 相关设置项已随功能回退移除）。
- **从旧 VB 版本升级**：不支持。本版已是纯 C# 运行时，VB 时代的运行时依赖与配置不再兼容。
- **渠道冻结**：`dev` 渠道自本版起冻结，不再接收新功能提交；后续缺陷修复进 `slush`，`rc` 发布后 `dev` 解冻并重新接收功能。
- **`main` 分支**：当前与 `slush` 保持一致，为默认分支，代表最新稳定基线。
- **分支命名**：远端只保留 `<代号>-<平台>` 形式（`dev-Windows`、`slush-Windows`、`alpha-Windows`、`beta-Windows`、`rc-Windows` 及对应 `-linux`），
  旧分支（`dev`、`dev.6-Windows`、`dev.6-Linux`、`slush`、`linux`、`meloongcore` 等）已删除。
