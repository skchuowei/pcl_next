## 本版本改动

### 新增：GitHub 自动更新与渠道晋级

- 启动后后台静默检查 GitHub Releases，发现新版本自动下载到临时目录，下载完成后弹窗让你选
  「立即重启更新 / 稍后」，不打断正在进行的下载或游戏启动。
- 更新渠道可选（`dev / slush / alpha / beta / rc`，默认跟随当前版本），**只升不降**，杜绝降级安装。
- **「陆续退出测试版」**开关：开启后持续生效，检测到更高渠道发布时一次跳到当前最稳定的渠道
  （dev → slush → alpha → beta → rc），此后拒绝低渠道更新，一路推进到 RC 后开关自动关闭。
  RC / 正式版编译时该选项自动隐藏（已到顶，无意义）。
- 设置页新增独立「自动更新」卡片承载上述选项；「检查更新」按钮改走新流程，若在设置里关闭
  更新则回退为打开 GitHub Releases 页面。
- 更新内核对 tag 的解析号段表与 CI 的版本注入脚本完全同源，避免客户端与服务端版本误判。

> 这是全新代码，虽然已通过编译与算法自检，但**真实 GitHub API 请求、下载、自替换重启的完整链路
> 尚无外部验证**——请优先测试这一块，遇到异常请附日志反馈。

### 关于页：「项目进度」改为「更新摘要」

- 关于页原「项目进度」卡片内容过时（仍写着"Phase 3-6 进行中""代号 dev"），现改为「更新摘要」，
  按 `dev → slush → alpha → beta` 路线记载各阶段更新要点，素材来自仓库真实发布说明。
- 同步修正过时的"开发阶段 / C# 重写进行中 / 未达 alpha 标准"文案，反映 Windows 线重写已完成的现状。
- 「作者与贡献」新增作者主页入口（github.com/skchuowei）。

### 修复：Beta 渠道更新日志为空

- 此前 Beta 渠道在更新日志分支里被漏掉，从旧版升级首次启动时弹窗显示"没有更新日志……"。
  现已补 Beta 专用分支，开发日志也补上 beta 的版本条目，升级提示可正常显示更新记录。
